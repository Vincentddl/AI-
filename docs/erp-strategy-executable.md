# ERP 股债利差估值择时 — 可执行策略手册

> 版本: 2026-08-21 | 状态: 生产可用 | 回测样本: 2019.12~2026.08 (80个月 ERP信号)
> 配套脚本: `~/ai-investment-research/scripts/erp_interval_dca_v2.py`
> 数据源: akshare (沪深300 PE + 10Y国债 + 515080 ETF单位净值)

---

## 一句话策略

**沪深300 ERP ≥ 5.5% 时开始定投 515080 中证红利 ETF，按区间分档投入；ERP<5% 完全不买。**

---

## 一、决策机制

### 1.1 主信号：沪深300 ERP

```
ERP = (1 / 沪深300 PE_TTM) × 100  −  10Y国债收益率
    = 沪深300 盈利收益率(%)     −  10年国债收益率(%)
```

**获取方式**：每月末跑 `erp_interval_dca_v2.py` → 自动计算 `erp` 字段

### 1.2 决策表（5档）

| ERP 区间 | 历史状态 | 基础档位 | B=3000元 | 执行动作 |
|:--:|------|:--:|:--:|------|
| < 5.0% | 一般/昂贵 | **WAIT** | **0 元** | 不买 |
| 5.0–5.5% | 观察 | 试探 | **0~1500 元** | 仅在 §1.3 二级过滤通过时买入 |
| 5.5–6.0% | 有吸引力 | 轻度 | **1500 元** | 直接买入 |
| 6.0–6.5% | 明显便宜 | 正常 | **3000 元** | 直接买入 |
| 6.5–7.0% | 很便宜 | 强档 | **4500 元** | 直接买入 |
| ≥ 7.0% | 极端机会 | 极强 | **6000 元** | 直接买入 |

### 1.3 二级过滤：中证红利自身估值（5.0–5.5% 区间必查，其他区间建议也查）

获取方式：脚本会自动打印 515080 ETF 的当前 PE 估值（来自 `fund_open_fund_info_em`）

| 中证红利 PE 分位 | 股息率利差 | 动作 |
|:--:|:--:|------|
| < 30% | 高 | **保持原档** |
| 30-60% | 中 | **下降一级** |
| > 60% | 低 | **下降两级** |

### 3.1 触发时机

- **每月最后一个交易日收盘后 16:00**（例: 5月最后一个交易日为 5/30）
- A股交易日内（非周末/节假日）
- 已清仓用户: 跳过

### 3.2 执行步骤

```
步骤 1: 运行回测脚本 (取 ERP)
  $ ~/AppData/Local/hermes/hermes-agent/venv/Scripts/python.exe \
    ~/ai-investment-research/scripts/erp_interval_dca_v2.py

  输出最后一行: "📌 当前决策: ..."

步骤 2: 解析输出
  - 找到 "ERP: X.XX%" 行
  - 找到 "📌 当前决策" 行
  - 根据决策表 → 决定本月买入金额

步骤 3: 中证红利二级过滤（仅 5.0-5.5% 必查，其他建议查）
  - 看脚本输出中的中证红利 PE 分位
  - 看蛋卷基金 https://danjuanfunds.com/djapi/index_eva/dj 获取实时 PE 分位

步骤 4: 执行买入

  - 515080 中证红利ETF 输入目标金额
  - 记录: 日期 / 买入金额 / ERP / 档位

  - 通过 wecom_send.py 推送决策结果
```

## 六、风险与边界

### 6.1 已知问题

1. **样本有限**：515080 ETF 仅 2019.12 起，6.5 年数据。回测胜率受单一周期影响大。
2. **ERP 历史分位滞后**：长期利率下行（10Y 从 4% → 1.7%），历史 ERP 比较基准已变。
3. **总账户 IRR 不等于单笔 IRR**：挑买点会闲置现金，总账户 IRR 约 6-7%（比单笔 7-10% 低）。
4. **中证红利 ≠ 沪深300**：信号与标的错位，二级过滤必须做。

### 6.2 何时停止策略

| 触发 | 动作 |
|------|------|
| 515080 连续 12 个月跑输中证红利指数 > 5% | 检查跟踪误差 |
| ERP 连续 6 个月 < 4% 且中证红利PE>70% 分位 | 整体降级 |
| 个人现金不足 | 自动暂停 |
| 沪深300 估值方法论变化 (如启用新PE算法) | 重测回测 |

## 七、回滚与升级路径

### 7.1 数据升级 (Tushare Pro)

当前用 akshare 的 ETF 单位净值（已含分红再投资）。如要更高精度：
- Tushare pro token 注册 → https://tushare.pro/register
- 调 `index_daily_full` 接口获得全收益指数
- 重新跑脚本，替换数据获取部分

### 7.2 策略参数升级

每月记录实际买入金额与建议金额的差异。每季度回测一次：
- 胜率波动 < 10% → 维持
- 胜率大幅下降 → 检查是否市场风格切换
- 单笔 IRR < 5% → 考虑放宽阈值或减少档位

## 八、关键纪律

1. **月度固定检查** — 不管盈亏，每月最后一个交易日都跑一次脚本
2. **坚持档位纪律** — 5.5% 给 1500 就买 1500，不要追加到 3000
3. **二级过滤必须做** — 5.0-5.5% 区间不查中证红利估值就是耍流氓
4. **不预测 ERP** — 不到月末不知道当月数据，**绝不提前买**
5. **3 年不评价** — 样本太短，6.5 年数据评不出胜率真伪
