## 七、宏观逃顶预警系统（四大信号详解）

### 信号1: 萨姆规则 (Sahm Rule) 📉

**公式**: `失业率_3MA - 失业率_12M最低 ≥ 0.5%`

**数据源**: FRED API — `UNRATE` 月度数据

```bash
curl -s "https://api.stlouisfed.org/fred/series/observations\
?series_id=UNRATE&api_key=$FRED_API_KEY&file_type=json&sort_order=desc&limit=15"
```

**计算步骤**:
```python
unrate = [4.1, 4.1, 4.2, ...]  # 最近15个月，从旧到新
ma3 = sum(unrate[-3:]) / 3
min12 = min(unrate[:-3])  # 不含最近3个月的12个月最低
sahm = ma3 - min12
# if sahm >= 0.5 → 触发
```

**历史胜率**: 1960年以来触发即衰退，100%准确  
**窗口期**: 触发→股市见顶约1-6个月  
**行动**: 2周内将权益仓位降至30%以下，转入货币基金/短债ETF

## 十三、技术指标计算（完整公式与Python实现）

### 13.1 MA（移动平均线）

```
MA(n) = SUM(CLOSE[-n:]) / n
```

```python
ma5 = sum(closes[-5:]) / 5
ma10 = sum(closes[-10:]) / 10
ma20 = sum(closes[-20:]) / 20
ma60 = sum(closes[-60:]) / 60
```

### 13.2 RSI（相对强弱指标, 14日）

```
RSI = 100 - 100 / (1 + RS)
RS = AvgGain(14) / AvgLoss(14)
```

```python
gains = [max(c[i]-c[i-1], 0) for i in range(-14, 0)]
losses = [max(c[i-1]-c[i], 0) for i in range(-14, 0)]
avg_gain = sum(gains)/14
avg_loss = sum(losses)/14
rsi = 100 - 100/(1 + avg_gain/avg_loss) if avg_loss > 0 else 100
```

### 13.3 MACD（指数平滑异同移动平均线）

```
EMA(n) = Price × k + EMA_prev × (1-k),  k = 2/(n+1)
DIF = EMA(12) - EMA(26)
DEA = EMA(DIF, 9)
MACD柱 = 2 × (DIF - DEA)
```

```python
def ema(data, period):
    k = 2/(period+1)
    result = [data[0]]
    for x in data[1:]:
        result.append(x*k + result[-1]*(1-k))
    return result

e12 = ema(closes, 12)
e26 = ema(closes, 26)
dif = [e12[i]-e26[i] for i in range(n)]
dea = ema(dif, 9)
bar = 2 * (dif[-1] - dea[-1])
```

### 13.4 KDJ（随机指标, 9,3,3）

```
RSV = (C - L9) / (H9 - L9) × 100
K = 2/3 × K_prev + 1/3 × RSV
D = 2/3 × D_prev + 1/3 × K
J = 3K - 2D
```

### 13.5 BOLL（布林带, 20,2）

```
MID = MA(20)
UPPER = MID + 2 × STD(20)
LOWER = MID - 2 × STD(20)
BANDWIDTH = (UPPER - LOWER) / MID × 100%
```

### 13.6 ATR（平均真实波幅, 14日）

```
TR = MAX(H-L, |H-C_prev|, |L-C_prev|)
ATR = AVG(TR, 14)
```

### 13.7 量比

```
量比 = 今日成交量 / 近5日均量
```

## 19. 技术指标体系（完整版）

### 19.0 设计原则

每个指标不是孤立看的，而是按**三层递进**来解读：

```
第一层 — 趋势定方向:  MA排列 / MACD趋势 / 布林带位置
第二层 — 动能测力度:  RSI / KDJ / MACD柱 / 量价关系
第三层 — 量能验真假:  量比 / 量价配合 / 放量缩量信号
```

**信号优先级**: 趋势层 > 动能层 > 量能层  
**即**: 即使KDJ金叉+放量，如果均线空头排列，也只能视为反弹而非反转。

---

### 19.1 均线系统 (MA)

#### 19.1.1 均线排列与趋势判定

| 排列 | 状态 | 含义 | 仓位建议 |
|------|:--:|------|:--:|
| MA5 > MA10 > MA20 > MA60 | 🟢 多头排列 | 上升趋势确认 | 可持有/加仓 |
| MA5/MA10纠缠 + MA20走平 | 🟡 震荡 | 方向不明 | 观望 |
| MA5 < MA10 < MA20 < MA60 | 🔴 空头排列 | 下降趋势确认 | 减仓/清仓 |
| MA5上穿MA10 | 🟢 金叉 | 短期转多信号 | 观察确认 |
| MA5下穿MA10 | 🔴 死叉 | 短期转空信号 | 准备减仓 |

#### 19.1.2 MA间距分析

```
MA间距 = (MA5 - MA20) / MA20 × 100%
```

| 间距 | 状态 | 含义 |
|:--:|:--:|------|
| > +5% | 🟢 乖离过大 | 短期超涨，有回调压力 |
| 0 ~ +5% | 🟢 健康多头 | 趋势良好 |
| 0 ~ -5% | 🟡 温和空头 | 可能反弹 |
| < -5% | 🔴 乖离过大 | 短期超跌，有反弹动力 |

#### 19.1.3 均线斜率

```python
MA5_slope = (MA5_today - MA5_5days_ago) / MA5_5days_ago × 100%
```

| 斜率 | 方向 | 强度 |
|:--:|:--:|:--:|
| > +1%/日 | ↑↑ | 强势上攻 |
| 0~+1%/日 | ↑ | 温和上涨 |
| -1%~0 | → | 走平/震荡 |
| < -1%/日 | ↓↓ | 加速下跌 |

#### 19.1.4 MA交易信号

| 信号 | 条件 | 强度 | 动作 |
|------|------|:--:|------|
| **均线金三角** | MA5金叉MA10 + 两者金叉MA20 + 放量 | ⭐⭐⭐ | 加仓确认 |
| **均线死三角** | MA5死叉MA10 + 两者死叉MA20 | ⭐⭐⭐ | 减仓 |
| **回踩MA20不破** | 价格回踩MA20后反弹 + MA20斜率>0 | ⭐⭐ | 加仓点 |
| **反弹MA20受阻** | 价格反弹碰MA20回落 + MA20斜率<0 | ⭐⭐ | 减仓点 |
| **一阳穿三线** | 单日大阳线(+3%+)同时站上MA5/MA10/MA20 | ⭐⭐⭐ | 强烈看多 |
| **一阴破三线** | 单日大阴线(-3%+)同时跌破MA5/MA10/MA20 | ⭐⭐⭐ | 强烈看空 |

### 19.2 MACD（指数平滑异同移动平均线）

#### 19.2.1 核心信号

| 信号 | 条件 | 含义 | 可靠性 |
|------|------|------|:--:|
| **金叉** | DIF上穿DEA | 买入信号 | ⭐⭐ |
| **死叉** | DIF下穿DEA | 卖出信号 | ⭐⭐ |
| **零轴上金叉** | DIF>0 且 金叉 | 多头强势买入 | ⭐⭐⭐ |
| **零轴下死叉** | DIF<0 且 死叉 | 空头强势卖出 | ⭐⭐⭐ |
| **零轴下金叉** | DIF<0 且 金叉 | 反弹/反转初期 | ⭐ |
| **零轴上死叉** | DIF>0 且 死叉 | 回调/见顶 | ⭐ |

#### 19.2.2 柱体分析

| 柱体变化 | 含义 |
|------|------|
| 绿柱缩短 → 红柱出现 | 空头衰竭，转多 |
| 红柱缩短 → 绿柱出现 | 多头衰竭，转空 |
| 红柱连续3天放大 | 多头加速 |
| 绿柱连续3天放大 | 空头加速 |

#### 19.2.3 MACD背离（高可靠性信号）

| 类型 | 条件 | 强度 | 含义 |
|------|------|:--:|------|
| **顶背离** | 股价新高 + DIF未新高 | ⭐⭐⭐ | 见顶预警，减仓 |
| **底背离** | 股价新低 + DIF未新低 | ⭐⭐⭐ | 见底信号，关注 |
| **二次顶背离** | 两次顶背离 | ⭐⭐⭐⭐ | 强烈见顶 |
| **二次底背离** | 两次底背离 | ⭐⭐⭐⭐ | 强烈见底 |

> ⚠️ MACD背离是**领先信号**，背离后可能还有一段趋势延续。不要见背离就立刻反向操作，等确认K线反转再行动。

#### 19.2.4 MACD综合评分

```
MACD评分 = 0

if DIF > DEA: 评分 += 1       # 金叉状态
if DIF > 0: 评分 += 1          # 零轴上
if MACD柱 > 前日MACD柱: 评分 += 1  # 柱体放大
if 底背离: 评分 += 2
if 顶背离: 评分 -= 2

评分范围: -2 ~ +5
≥3: 强势看多
1~2: 温和看多
0: 中性
-1~-2: 看空
```

### 19.7 ATR（平均真实波幅）

#### 19.7.1 ATR用途

```
ATR = 标的的"正常日波动范围"

用法:
- 止损设置: 入场价 - 2×ATR
- 仓位计算: 单笔风险金额 / (股数 × 2×ATR)
- 波动预警: ATR突然放大>50% → 异常波动，暂停交易
```

#### 19.7.2 ATR信号

| ATR变化 | 含义 |
|------|------|
| ATR持续走高 | 波动加剧，趋势可能加速或反转 |
| ATR持续走低 | 波动收敛，变盘前兆 |
| ATR突然跳升 > 50% | 异常波动，暂停新开仓 |
| ATR/价格 > 5% | 高波动标的，减仓操作 |
