## 19. 技术指标体系（完整版）

### 19.0 设计原则

每个指标不是孤立看的，而是按**三层递进**来解读：

```
第一层 — 趋势定方向:  MA排列 / MACD趋势 / 布林带位置
第二层 — 动能测力度:  RSI / KDJ / MACD柱 / 量价关系
第三层 — 量能验真假:  量比 / 量价配合 / 放量缩量信号
```

**信号优先级**: 趋势层 > 动能层 > 量能层  
**即**: 即使KDJ金叉+放量，如果均线空头排列，也只能视为反弹而非反转。

### 19.1 均线系统 (MA)

#### 19.1.1 均线排列与趋势判定

| 排列 | 状态 | 含义 | 仓位建议 |
|------|:--:|------|:--:|
| MA5 > MA10 > MA20 > MA60 | 🟢 多头排列 | 上升趋势确认 | 可持有/加仓 |
| MA5/MA10纠缠 + MA20走平 | 🟡 震荡 | 方向不明 | 观望 |
| MA5 < MA10 < MA20 < MA60 | 🔴 空头排列 | 下降趋势确认 | 减仓/清仓 |
| MA5上穿MA10 | 🟢 金叉 | 短期转多信号 | 观察确认 |
| MA5下穿MA10 | 🔴 死叉 | 短期转空信号 | 准备减仓 |

#### 19.1.2 MA间距分析

```
MA间距 = (MA5 - MA20) / MA20 × 100%
```

| 间距 | 状态 | 含义 |
|:--:|:--:|------|
| > +5% | 🟢 乖离过大 | 短期超涨，有回调压力 |
| 0 ~ +5% | 🟢 健康多头 | 趋势良好 |
| 0 ~ -5% | 🟡 温和空头 | 可能反弹 |
| < -5% | 🔴 乖离过大 | 短期超跌，有反弹动力 |

#### 19.1.3 均线斜率

```python
MA5_slope = (MA5_today - MA5_5days_ago) / MA5_5days_ago × 100%
```

| 斜率 | 方向 | 强度 |
|:--:|:--:|:--:|
| > +1%/日 | ↑↑ | 强势上攻 |
| 0~+1%/日 | ↑ | 温和上涨 |
| -1%~0 | → | 走平/震荡 |
| < -1%/日 | ↓↓ | 加速下跌 |

#### 19.1.4 MA交易信号

| 信号 | 条件 | 强度 | 动作 |
|------|------|:--:|------|
| **均线金三角** | MA5金叉MA10 + 两者金叉MA20 + 放量 | ⭐⭐⭐ | 加仓确认 |
| **均线死三角** | MA5死叉MA10 + 两者死叉MA20 | ⭐⭐⭐ | 减仓 |
| **回踩MA20不破** | 价格回踩MA20后反弹 + MA20斜率>0 | ⭐⭐ | 加仓点 |
| **反弹MA20受阻** | 价格反弹碰MA20回落 + MA20斜率<0 | ⭐⭐ | 减仓点 |
| **一阳穿三线** | 单日大阳线(+3%+)同时站上MA5/MA10/MA20 | ⭐⭐⭐ | 强烈看多 |
| **一阴破三线** | 单日大阴线(-3%+)同时跌破MA5/MA10/MA20 | ⭐⭐⭐ | 强烈看空 |

### 19.2 MACD（指数平滑异同移动平均线）

#### 19.2.1 核心信号

| 信号 | 条件 | 含义 | 可靠性 |
|------|------|------|:--:|
| **金叉** | DIF上穿DEA | 买入信号 | ⭐⭐ |
| **死叉** | DIF下穿DEA | 卖出信号 | ⭐⭐ |
| **零轴上金叉** | DIF>0 且 金叉 | 多头强势买入 | ⭐⭐⭐ |
| **零轴下死叉** | DIF<0 且 死叉 | 空头强势卖出 | ⭐⭐⭐ |
| **零轴下金叉** | DIF<0 且 金叉 | 反弹/反转初期 | ⭐ |
| **零轴上死叉** | DIF>0 且 死叉 | 回调/见顶 | ⭐ |

#### 19.2.2 柱体分析

| 柱体变化 | 含义 |
|------|------|
| 绿柱缩短 → 红柱出现 | 空头衰竭，转多 |
| 红柱缩短 → 绿柱出现 | 多头衰竭，转空 |
| 红柱连续3天放大 | 多头加速 |
| 绿柱连续3天放大 | 空头加速 |

#### 19.2.3 MACD背离（高可靠性信号）

| 类型 | 条件 | 强度 | 含义 |
|------|------|:--:|------|
| **顶背离** | 股价新高 + DIF未新高 | ⭐⭐⭐ | 见顶预警，减仓 |
| **底背离** | 股价新低 + DIF未新低 | ⭐⭐⭐ | 见底信号，关注 |
| **二次顶背离** | 两次顶背离 | ⭐⭐⭐⭐ | 强烈见顶 |
| **二次底背离** | 两次底背离 | ⭐⭐⭐⭐ | 强烈见底 |

> ⚠️ MACD背离是**领先信号**，背离后可能还有一段趋势延续。不要见背离就立刻反向操作，等确认K线反转再行动。

#### 19.2.4 MACD综合评分

```
MACD评分 = 0

if DIF > DEA: 评分 += 1       # 金叉状态
if DIF > 0: 评分 += 1          # 零轴上
if MACD柱 > 前日MACD柱: 评分 += 1  # 柱体放大
if 底背离: 评分 += 2
if 顶背离: 评分 -= 2

评分范围: -2 ~ +5
≥3: 强势看多
1~2: 温和看多
0: 中性
-1~-2: 看空
```

### 19.3 KDJ（随机指标）

#### 19.3.1 超买超卖区间

| K值区间 | 状态 | 含义 |
|:--:|:--:|------|
| > 80 | 🔴 超买 | 短期过热，回调压力大 |
| 50~80 | 🟢 偏多 | 多头掌控 |
| 20~50 | 🟡 偏空 | 空头掌控 |
| < 20 | 🔵 超卖 | 短期超跌，反弹动力强 |

#### 19.3.2 KDJ交叉信号

| 信号 | 条件 | 可靠性 |
|------|------|:--:|
| **低位金叉** | K上穿D + K<30 | ⭐⭐⭐ |
| **高位死叉** | K下穿D + K>70 | ⭐⭐⭐ |
| **中位金叉** | K上穿D + 30<K<70 | ⭐⭐ |
| **中位死叉** | K下穿D + 30<K<70 | ⭐⭐ |

#### 19.3.3 J值极端信号

| J值 | 含义 | 有效期 |
|:--:|------|:--:|
| > 100 | 极度超买 | 1-3天见顶 |
| < 0 | 极度超卖 | 1-3天见底 |
| J上穿K/D | 金叉确认 | — |

#### 19.3.4 KDJ背离

| 类型 | 条件 | 可靠性 |
|------|------|:--:|
| KDJ顶背离 | 股价新高 + KD未新高 | ⭐⭐ |
| KDJ底背离 | 股价新低 + KD未新低 | ⭐⭐ |

> ⚠️ KDJ波动快，假信号多。**KDJ信号必须和MA/MACD趋势方向一致才有效**。  
> 例如：均线空头中，KDJ低位金叉只意味着"短期超跌反弹"，不代表反转。

### 19.4 RSI（相对强弱指标）

#### 19.4.1 区间判断

| RSI | 状态 | 含义 |
|:--:|:--:|------|
| > 80 | 🔴 极度超买 | 强烈回调压力 |
| 70~80 | 🔴 超买 | 短期过热 |
| 50~70 | 🟢 偏多 | 多头市场 |
| 30~50 | 🟡 偏空 | 空头市场 |
| 20~30 | 🔵 超卖 | 短期超跌 |
| < 20 | 🔵 极度超卖 | 强烈反弹动力 |

#### 19.4.2 RSI背离

| 类型 | 条件 | 可靠性 |
|------|------|:--:|
| RSI顶背离 | 股价新高 + RSI未新高 | ⭐⭐⭐ |
| RSI底背离 | 股价新低 + RSI未新低 | ⭐⭐⭐ |

> RSI背离比KDJ背离更可靠。RSI底背离+MACD底背离同时出现 → 极大概率见底。

#### 19.4.3 RSI形态

| 形态 | 含义 |
|------|------|
| RSI > 50且持续走高 | 多头趋势健康 |
| RSI在40-60反复穿50 | 震荡市，方向不明 |
| RSI < 50且持续走低 | 空头趋势持续 |

### 19.5 成交量分析

#### 19.5.1 量比信号

| 量比 | 状态 | 含义 |
|:--:|:--:|------|
| > 2.0 | 🔴 巨量 | 极端情绪，通常为转折点 |
| 1.5~2.0 | 🟡 放量 | 显著放量，关注方向 |
| 0.7~1.5 | 🟢 正常 | 正常交投 |
| 0.5~0.7 | 🟡 缩量 | 交投清淡 |
| < 0.5 | 🔵 地量 | 极端缩量，通常为变盘前兆 |

#### 19.5.2 量价配合（核心）

| 价格 | 成交量 | 信号 | 含义 |
|:--:|:--:|:--:|------|
| ↑ | ↑ | 🟢 **价涨量增** | 健康上涨，趋势延续 |
| ↑ | ↓ | 🔴 **价涨量缩** | 量价背离，上涨乏力 |
| ↓ | ↑ | 🔴 **价跌量增** | 恐慌抛售或主力出货 |
| ↓ | ↓ | 🟢 **价跌量缩** | 抛压减轻，可能止跌 |
| → | ↑ | 🟡 **价平量增** | 变盘前兆，关注突破方向 |
| → | ↓ | 🟡 **价平量缩** | 观望情绪浓厚 |

#### 19.5.3 特殊量价形态

| 形态 | 特征 | 含义 |
|------|------|------|
| **放量突破** | 价格突破关键均线 + 量比>1.5 | ⭐⭐⭐ 有效突破 |
| **缩量突破** | 价格突破均线 + 量比<1.0 | ⭐ 假突破概率大 |
| **天量天价** | 阶段性最大量 + 最高价 | 短期见顶 |
| **地量地价** | 阶段性最小量 + 最低价 | 短期见底 |
| **堆量** | 连续3天+量比>1.2 | 主力资金介入 |
| **散量** | 持续量比<0.7 | 无人关注，不参与 |

### 19.6 布林带 (BOLL)

#### 19.6.1 位置判断

| 位置 | 状态 | 含义 |
|------|:--:|------|
| 上轨之上 | 🔴 超涨 | 短期过热 |
| 中轨→上轨 | 🟢 偏多 | 多头区间 |
| 下轨→中轨 | 🟡 偏空 | 空头区间 |
| 下轨之下 | 🔵 超跌 | 短期超跌 |

#### 19.6.2 带宽信号

| 带宽 | 状态 | 含义 |
|:--:|:--:|------|
| < 5% | 极度收窄 | 变盘前兆（方向待定） |
| 5~10% | 收窄中 | 即将选择方向 |
| 10~20% | 正常 | — |
| > 20% | 扩张 | 趋势加速 |
| > 30% | 极度扩张 | 恐慌或狂热，即将回归 |

#### 19.6.3 布林带交易信号

| 信号 | 条件 | 强度 |
|------|------|:--:|
| **下轨反弹** | 触及下轨后收阳 + RSI<30 + MACD收敛 | ⭐⭐⭐ 买入 |
| **上轨受阻** | 触及上轨后收阴 + RSI>70 | ⭐⭐⭐ 卖出 |
| **布林开口向上** | 带宽扩大 + 价格沿上轨运行 | ⭐⭐ 强势 |
| **布林开口向下** | 带宽扩大 + 价格沿下轨运行 | ⭐⭐ 弱势 |

### 19.7 ATR（平均真实波幅）

#### 19.7.1 ATR用途

```
ATR = 标的的"正常日波动范围"

用法:
- 止损设置: 入场价 - 2×ATR
- 仓位计算: 单笔风险金额 / (股数 × 2×ATR)
- 波动预警: ATR突然放大>50% → 异常波动，暂停交易
```

#### 19.7.2 ATR信号

| ATR变化 | 含义 |
|------|------|
| ATR持续走高 | 波动加剧，趋势可能加速或反转 |
| ATR持续走低 | 波动收敛，变盘前兆 |
| ATR突然跳升 > 50% | 异常波动，暂停新开仓 |
| ATR/价格 > 5% | 高波动标的，减仓操作 |

### 19.8 综合信号评分系统

> 每个技术指标给出 -2 ~ +2 分，汇总后判定整体技术面强弱。

#### 19.8.1 评分表

| 指标 | -2 (强烈看空) | -1 (偏空) | 0 (中性) | +1 (偏多) | +2 (强烈看多) |
|------|------|------|------|------|------|
| **MA排列** | 空头排列 + MA5破MA60 | 空头排列 | 纠缠不清 | 多头排列 | 多头排列 + 金三角 |
| **MA位置** | 破所有均线 | 破MA20 | 在MA20附近 | 站上MA5/MA10 | 站上所有均线 |
| **MACD** | 零轴下死叉+绿柱放大 | 零轴下死叉 | 零轴附近纠缠 | 零轴上金叉 | 零轴上金叉+红柱放大 |
| **MACD背离** | 顶背离确认 | 顶背离雏形 | 无背离 | 底背离雏形 | 底背离确认 |
| **KDJ** | K<20 钝化 | K在20-50 | K在50附近 | K在50-80 | K>80 强势 |
| **RSI** | RSI<20 | RSI 20-40 | RSI 40-60 | RSI 60-80 | RSI>80 |
| **量价** | 价跌量增 | 价平量缩 | 量价正常 | 价涨量平 | 价涨量增 |
| **布林带** | 沿下轨运行 | 中轨下方 | 中轨附近 | 中轨上方 | 沿上轨运行 |
| **ATR** | ATR跳升>50% | ATR走高 | ATR正常 | ATR正常 | ATR走低(收敛待突破) |

#### 19.8.2 评分判读

| 总分 | 技术面判断 | 仓位建议 |
|:--:|------|:--:|
| **≥ +10** | 🟢 强烈看多 | 可加仓（不超过10%） |
| **+5 ~ +9** | 🟢 偏多 | 持有，等更好买点 |
| **-4 ~ +4** | 🟡 震荡/矛盾 | 观望，不做新操作 |
| **-9 ~ -5** | 🔴 偏空 | 减仓10-20% |
| **≤ -10** | 🔴 强烈看空 | 清仓或大幅减仓 |

### 19.9 多时间框架确认

#### 19.9.1 ETF适用的时间框架

```
日线:  定方向（MA排列/MACD趋势）
60分钟: 找入场点（KDJ金叉/放量突破）
15分钟: 精确入场（分时图量价配合）
```

| 日线 | 60分钟 | 操作 |
|:--:|:--:|------|
| 多头 | 多头 | ✅ 做多 |
| 多头 | 回调 | 等60分钟转多再入 |
| 空头 | 多头 | ⚠️ 仅短线反弹，不重仓 |
| 空头 | 空头 | ❌ 不做多 |

#### 19.9.2 共振加分

```
日线MA金叉 + 60分钟MA金叉 = ⭐⭐⭐ 强烈做多
日线MACD金叉 + 60分钟MACD金叉 = ⭐⭐⭐
日线底背离 + 60分钟底背离 = ⭐⭐⭐⭐ 极大概率反转
```

### 19.10 技术指标与闸门联动

```
技术综合评分 ≥ +5  AND  闸门1✅  AND  闸门2✅  → 可以考虑加仓
技术综合评分 ≤ -5  → 不管闸门状态 → 至少减仓10%
MACD顶背离 + RSI>70  → 无论其他信号 → 至少减仓10%
MACD底背离 + RSI<30  → 标记"密切关注"，但不自动加仓（需等MA确认）
```

### 19.11 与现有风控规则的优先级

```
用户硬规则（破5日线减仓/破20日清仓） ← 第1优先级
    ↓
闸门5 宏观逃顶 ← 第2优先级
    ↓
技术综合评分 ← 第3优先级（本章新增）
    ↓
闸门1-4 ← 第4优先级
    ↓
主观判断 ← 最后参考
```

> **技术评分不能覆盖用户硬规则。** 即使技术评分+12分，如果已经跌破MA20且次日未收回，依然要清仓。

### 19.12 指标解读速查卡

| 你想知道... | 看这个 |
|------|------|
| 现在是多头还是空头市场？ | MA排列 + MA20方向 |
