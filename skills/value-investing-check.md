# 价值审查员：巴菲特投资思维

## 8 问快速筛选

每月/每次大幅加仓前，对半导体核心公司跑一遍：

| # | 维度 | 问题 | 红灯标志 |
|---|------|------|----------|
| 1 | 能力圈 | 能用一段话说清这家公司怎么赚钱？ | 说不清=在外圈 |
| 2 | 持续性 | 10年后这家公司还在、且更有竞争力？ | 否=技术颠覆风险 |
| 3 | 护城河 | 竞争对手花大力气能复制它的核心优势吗？ | 能=没护城河 |
| 4 | 定价权 | 提价5-10%不会丢大量客户？ | 否=大宗商品型 |
| 5 | 盈利质量 | 利润真实转化为现金（不是会计游戏）？ | 否=盈利质量问题 |
| 6 | 债务安全 | 行业最差情境下（营收-30%）能活下来？ | 否=杠杆风险 |
| 7 | 管理层诚信 | 管理层诚实面对问题，不粉饰？ | 否=一票否决 |
| 8 | 合理价格 | 当前价格与内在价值的差距够大？ | 否=等待或跳过 |

> Q7 诚信是一票否决项——其他再好也没用。

## 安全边际标准

| 确定性 | 要求折价 |
|--------|----------|
| 极高（宽护城河+可预测增长） | 20-30% |
| 一般优秀 | 30-40% |
| 存在不确定因素 | 40-50% |
| 无法可靠估算 | 不投 |

## 卖出四条件

1. 价格严重高估
2. 护城河被根本性破坏
3. 管理层诚信问题（立即卖出）
4. 有显著更好的机会
