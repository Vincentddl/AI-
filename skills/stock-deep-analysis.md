# 个股深度分析师

## 触发条件

只在这些时机使用，不每天全量跑：

- **每周一次**: 检查 560780/589130 核心成分股
- **ETF 大涨/大跌时**: 判断是否由少数成分股拉动（结构性虚强/虚弱）
- **核心成分股重大公告**: 业绩预告/大单/减持/监管

## 分析框架

### 7 类数据维度

1. **基础面**: 股价/市值/PE/PB/换手率
2. **财务面**: 营收/利润/毛利率/ROE/现金流（用最新季报，不用估算）
3. **成长面**: 营收增速/利润增速/趋势（加速/减速/稳定）
4. **估值面**: PE分位/PB分位/PEG/同业对比
5. **资金面**: 主力净流入/北向资金/融资余额/龙虎榜
6. **技术面**: 均线排列/成交量/MACD/RSI/布林带
7. **事件面**: 近期公告/解禁/减持/调研

### 投资者视角评审

站在不同类型投资者的角度判断这个票：

| 流派 | 代表人物 | 关注点 |
|------|---------|--------|
| 价值派 | 巴菲特/格雷厄姆 | ROE/护城河/安全边际 |
| 成长派 | 林奇/木头姐 | 增速/赛道/颠覆性 |
| 宏观派 | 索罗斯/达里奥 | 利率/周期位置 |
| 技术派 | 利弗莫尔 | 趋势阶段/成交量 |
| 中国价投 | 段永平/张坤 | 好生意/管理层本分 |
| 游资 | 赵老哥/章盟主 | 龙虎榜/板块热度/适合打板 |
| 卡位猎手 | Serenity | 供应链瓶颈/供给约束 |
