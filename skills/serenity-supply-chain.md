# Serenity 供应链瓶颈猎手

## 核心方法论

不买已被充分定价的龙头，沿供应链往上游拆，找到 "全世界绕不过去、又最容易供给见底" 的环节，抢在市场定价之前识别。

```
龙头被买爆 → 沿供应链往上拆 → 找最难替代的环节 → 
找该环节里供给最紧的标的 → 判断A股映射 → 排序优先研究名单
```

## 判定一个环节是否为 "卡位点"

三要素：
1. **难替代**: 换供应商/材料/工艺要多久？越久越好
2. **供给紧**: 现有产能+在建产能能否跟上AI需求？
3. **没被定价**: 市场还在用旧叙事看它（"周期股/老半导体"），没意识到已被AI需求绑定

## AI半导体产业链层级

```
下游需求: 智算中心/AI服务器/GPU集群
    ↓
系统集成: 服务器/交换机组装
    ↓
模块/子系统: 光模块(800G/1.6T)、HBM内存、CoWoS封装
    ↓
芯片/器件: GPU/AI芯片、EML激光器、DSP、HBM控制器
    ↓
制造/封测: 先进制程(3nm/5nm)、Chiplet、3D封装、CMP
    ↓
设备: 刻蚀/薄膜沉积/光刻/检测 — ⚠️ 核心卡位层
    ↓
材料/耗材: 硅片/光刻胶/CMP抛光液/特种气体/前驱体
    ↓
物理基础设施: 电力/冷却/超纯水
```

## 优先级判断：HBM > CoWoS先进封装 > 光模块/高速互联

| 层级 | 卡点逻辑 | A股映射 |
|------|---------|---------|
| HBM | 供给最紧、扩产最慢、三星/SK垄断 | 设备/材料/封测间接受益 |
| CoWoS先进封装 | 台积电独家、扩产2年+ | 通富/长电/华天等封测 |
| 光模块/高速互联 | 800G→1.6T升级、EML芯片缺 | 中际/新易盛/天孚/光迅 |
| 半导体设备 | 国产替代订单集中交付 | 中微/拓荆/北方华创/长川 |
