# 同花顺 K 线买卖策略（均线趋势风控 · 执行层）

> 可直接粘贴到同花顺「AI策略编辑助手」或「公式管理器」。
> 这是**执行层**（画买卖点信号），配合 `01-ERP估值择时` 决定何时买、买多少。

---

## 定位

ERP 择时管"**什么估值该买、买多少**"；本策略管"**K 线上的买卖点信号**"。卖出纪律与主手册风险官一致。

## 主图策略公式（同花顺 → 公式管理器 → 技术指标/画线型）

```
{============================================}
{ 红利低波·趋势纪律策略 (可用于512890/510880等) }
{ 买: 站上MA5 + MA5>MA20 + MACD多头 + 温和放量 }
{ 减: 跌破MA5 }
{ 清: 跌破MA20 且 次日收不回来 / 放量长阴 }
{============================================}
MA5:MA(CLOSE,5),COLORWHITE;
MA10:MA(CLOSE,10),COLORYELLOW;
MA20:MA(CLOSE,20),COLORRED;
MA60:MA(CLOSE,60),COLORGREEN;
DIF:=EMA(CLOSE,12)-EMA(CLOSE,26);
DEA:=EMA(DIF,9);
VOL5:=MA(VOL,5);
BUY:=CROSS(CLOSE,MA5) AND MA5>MA20 AND DIF>DEA AND VOL>VOL5*0.8;
SELL1:=CROSS(MA5,CLOSE);
SELL2:=CLOSE<MA20 AND REF(CLOSE,1)<REF(MA20,1);
SELL3:=CLOSE/REF(CLOSE,1)<0.97 AND VOL>VOL5*1.5;
DRAWICON(BUY,LOW*0.985,1);
DRAWTEXT(BUY,LOW*0.965,'买'),COLORRED;
DRAWICON(SELL1,HIGH*1.015,2);
DRAWTEXT(SELL1,HIGH*1.035,'减'),COLORWHITE;
DRAWICON(SELL2 OR SELL3,HIGH*1.015,2);
DRAWTEXT(SELL2 OR SELL3,HIGH*1.035,'清'),COLORGREEN;
```

**图例**：🔴"买"=买入信号 ｜ 白"减"=跌破MA5减仓 ｜ 绿"清"=跌破MA20次日未收回·清仓 / 放量长阴止损

## 选股公式（全市场扫买点）

```
CLOSE>MA(CLOSE,5)
AND MA(CLOSE,5)>MA(CLOSE,20)
AND EMA(CLOSE,12)-EMA(CLOSE,26)>EMA(EMA(CLOSE,12)-EMA(CLOSE,26),9)
AND VOL>MA(VOL,5)*0.8;
```

## 与 ERP 的配合规则

| ERP 档位 | 外部决策 | 结合 K 线信号 |
|---------|---------|-------------|
| ERP < 5.5% | 🔴 不买 | 出现"买"信号也忽略（估值太贵） |
| ERP ≥ 5.5% | 🟢 可买 1B~3B | 出现"买"信号 → 按档位金额买入 |
| 任意 | — | "减"→减10-20%；"清"→清仓 |

> ⚠️ 铁律：宏观闸门5 触发（≥2 逃顶信号）时，无视 K 线信号直接防御减仓。

## 验证 vs 用户纪律

| 纪律 | 公式 | 一致性 |
|------|------|:--:|
| 跌破5日线→减仓 | `SELL1=CROSS(MA5,CLOSE)` | ✅ |
| 跌破20日线且次日收不回→清仓 | `SELL2=CLOSE<MA20 AND REF(CLOSE,1)<REF(MA20,1)` | ✅ |
| 站上MA20中期健康才买 | `BUY` 要求 `MA5>MA20` | ✅ |
| 不追高、放量长阴止损 | `SELL3` 量比>1.5+跌>3% | ✅ |
