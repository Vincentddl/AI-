## 策略与目标的映射

| 策略 | 目标 | 所在分类 |
|------|------|---------|
| ERP 分档定投（估值择时） | 决定"买入时机 + 买入量" | `01-ERP估值择时` |
| 红利指数搭配 | 决定"买哪只红利，进攻/防守" | `01-ERP估值择时` + `02` |
| 均线趋势纪律 | 决定"买卖点信号"（执行层） | `03-ETF均线风控` |
| 宏观逃顶 | 系统性风险 → 清仓防御 | `04-宏观逃顶` |

## 通用架构：择时 vs 执行

```
1. 择时层（ERP）: 什么价位/估值该买、买多少  → 01-ERP估值择时
2. 执行层（技术）: K线上的买卖点信号           → 03-ETF均线风控
3. 风控层（宏观）: 系统性风险防御（优先于一切）  → 04-宏观逃顶
```
