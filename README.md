## 四道风控闸门

1. **数据闸门** — 数据缺失则禁止加仓
2. **趋势闸门** — 跌破10日线+板块走弱则禁止加仓
3. **风险官闸门** — 高风险评级则降级所有看多建议
4. **回测闸门** — 新规则未经验证则只允许观察

## 风险官规则（10条减仓触发条件）

1. 跌破5日线后30分钟不收回
2. 跌破10日线且板块同步走弱
3. 跌破20日线
4. 高开低走
5. 放量长阴（跌幅>3%且量比>1.5）
6. 外盘半导体大跌（SOX<-3%）
7. 韩国半导体走弱
8. A股半导体弱于大盘
9. 成交量异常萎缩
10. 513310溢价/折价异常
